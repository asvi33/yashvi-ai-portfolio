# Yashvi Ambaliya — AI / Software Engineering Portfolio

A responsive portfolio built with plain HTML, CSS and JavaScript.

## Highlights
- AI/ML and Software Engineering positioning
- Project category filters
- Dark mode
- Responsive mobile navigation
- Scroll-reveal animations
- Skills and engineering focus cards
- Project, experience, education and contact sections
- Professional profile image

## Run locally
Open `index.html` in a browser.

## GitHub Pages
Create a repository, upload all files to the repository root, then use:
**Settings → Pages → Deploy from a branch → main → / (root)**.

The AI/ML and software-engineering focus language is presented as areas of interest/focus; project and experience claims are based on the supplied resume.
